Canvas API

Use currentDocument in the editor below to create and organize vertices, groups, selections, and the viewport. The browser's document API remains available.

Vertices

Create points individually or in batches. Updates change only the supplied fields; removal accepts one index or a list of indices.

currentDocument.vertices.list()
currentDocument.vertices.get(index)
currentDocument.vertices.create(x, y, name?)
currentDocument.vertices.createMany([{ x, y, name? }])
currentDocument.vertices.update(index, { x, y, name })
currentDocument.vertices.remove(index | indices)
currentDocument.vertices.clear()
currentDocument.vertices.renameSelected(baseName)

Groups

Groups render their member vertices with their own primitive type. Creating a group returns its ID for later updates or removal.

currentDocument.groups.list()
currentDocument.groups.get(id)
currentDocument.groups.create(indices, { name?, primitiveType? })
currentDocument.groups.update(id, { name, primitiveType, indices })
currentDocument.groups.remove(id)
currentDocument.groups.ungroup(id)

Selection and view

Selection methods control the highlighted vertices. View methods recenter the canvas or restore its default position and zoom.

currentDocument.selection.get()
currentDocument.selection.set(indices)
currentDocument.selection.clear()

currentDocument.view.centerOn(indices)
currentDocument.view.reset()
currentDocument.getPrimitiveType()
